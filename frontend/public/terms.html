YouTube Description Editor is a personal tool for one person, its owner, to edit the descriptions, titles and tags of their own YouTube videos. It isn't offered as a service to anyone else, and only the owner's Google account can sign in.

  • By signing in, the owner agrees to these terms and to the YouTube Terms of Service, since the app uses YouTube API Services.

The app is provided as is, without warranty of any kind. It backs up each video's details before changing it, and changes can be restored, but the owner uses it at their own risk.
