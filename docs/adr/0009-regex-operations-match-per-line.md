# Regex Operations: per-line anchors, a time limit, and literal plain text

Find and replace in regex mode always runs with `^` and `$` matching at each line (MULTILINE), because descriptions are edited line by line ("remove the line that starts with `Spotify:`"). Whole-description anchoring is still available with `\A` and `\Z`. Patterns use Python's `regex` package with a 0.25 s limit per description, so a catastrophic pattern fails with a message instead of freezing the app. Replacement group references are checked against the pattern before any description is touched. In plain mode, the find and replace texts are always literal: no escapes and no groups. Saved Runs record the Operation, so changing these semantics later would change what an old Operation means. That's why it's recorded here.
